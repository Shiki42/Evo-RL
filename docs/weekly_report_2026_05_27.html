一、强化学习数据质量：从 VLA rollout 转向高质量示范

原论文路径使用 SFT pi0.5 生成推理数据，再训练强化学习模块。但在当前 SO-101 推理场景下，SFT pi0.5 生成的数据存在明显动作抖动和 chunk 边界不连续；这类数据进入 replay buffer 后，会把 actor-critic 拉向不稳定动作分布，对训练效果形成负贡献。本周改用纯人类遥操作数据训练后，actor-critic 结果显著改善，说明模型容量并非主要矛盾，数据分布质量才是第一优先级。

判断：后续工作不应继续扩大低质量 VLA rollout 规模，而应优先改善“自主推理 + 人工干预”数据的动作连续性、接管稳定性和记录口径。只有 rollout 数据质量可控，RL 模块的性能提升才具备可发布性。

二、改善 rollout 数据质量的当前方案

1. RTC 异步推理与重叠平滑

已引入 pi 官方推荐的 real-time chunk 思路：新旧 chunk 重叠部分使用旧 chunk 剩余动作作为约束，降低边界跳变。

2. 降低采集推理频率

当前 16 精度单次推理约 192-214ms。30Hz 下等价于 6-7 步 delay，10-step chunk 只剩 3-4 步；采集 rollout 时降到 20Hz 后，剩余可平滑步数可提升到约 5-6 步。

3. 人工接管 follower action blend

进入人工后前 0.3-0.4s 使用 sent = (1-alpha) * last_policy_action + alpha * teleop_action，避免 leader 瞬时失力矩导致 follower 跟随跳变。
